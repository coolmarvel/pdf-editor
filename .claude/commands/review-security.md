# /review-security - 보안 리뷰 (pdf-editor)

현재 변경분(또는 인자로 지정한 범위)을 보안 관점에서 리뷰한다.

## 점검 항목

1. **시크릿**: 하드코딩된 토큰·키·비밀번호, `.env`·OAuth client secret 값의 코드·문서·로그 유출
2. **입력 검증**: 열기·드롭·이미지 가져오기 경로(파일 크기·형식), IPC(`window.api`) 인자와 메인 프로세스의 파일 경로 처리
3. **Electron 보안**: `contextIsolation`·`sandbox`·`nodeIntegration`·CSP(`'wasm-unsafe-eval'` 외 완화 없음)·`shell.openExternal` 대상 URL 검증·새 창 생성 차단
4. **경로 조작**: 저장·임시본·크래시 복구 파일 경로 조합(사용자 입력 파일명)
5. **XSS/출력 이스케이프**: 파일명·노트·링크 URL 이 HTML 로 렌더되는 경로, 링크 주석 URL 스킴
6. **PII/로그**: 사용자 문서 내용·경로가 로그·크래시 덤프로 흘러가는 곳
7. **엔진 입력**: wasm 워커에 들어가는 PDF 는 신뢰할 수 없는 입력이다. 패닉·무한 루프·메모리 폭주(워커 재시작 상한)
8. **의존성**: 알려진 취약 버전, 불필요하게 넓은 권한의 패키지

## 출력 형식

발견 항목을 **Critical / Warning / Info** 로 분류하고, 각 항목에 `파일:라인` 을 인용한다.
수정 제안을 함께 제시하되, 적용은 사용자 승인 후에 한다. 발견이 없으면 "없음"을 항목별로 명시한다.
